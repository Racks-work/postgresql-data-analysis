# PostgreSQL Data Analysis Portfolio

**Jabrial Gardner** | Computer Science | SQL · PostgreSQL · Data Analytics

A curated collection of PostgreSQL analysis exercises based on college coursework, focused on public-library usage and demographic data. This repository is a **portfolio starter**: the included queries have not yet been executed against the original datasets in this package.

## Skills demonstrated
- Aggregations, filtering, and calculated metrics
- Window functions and rankings
- Joins across annual datasets
- Correlation analysis with PostgreSQL statistical functions

## Project structure
- `sql/01_library_visits.sql` — library visit rates and ranking
- `sql/02_library_changes.sql` — year-over-year library comparisons
- `sql/03_education_income.sql` — education/income correlation
- `docs/DATA_SETUP.md` — required tables, validation, and data sourcing

## Run the queries
1. Install PostgreSQL and open pgAdmin or `psql`.
2. Import datasets using your course-provided schema scripts and CSVs **only when you have permission to share/use them**.
3. Check table names and column types against `docs/DATA_SETUP.md`.
4. Run each SQL file. Save your own output screenshots to `screenshots/`.
5. Record actual observations and test results below; don't claim results before running.
